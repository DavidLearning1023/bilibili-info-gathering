# `examples/` —— 渲染样例

> ⚠️ **本目录是真实运行产物**，包含**公开可见**的视频标题、BV 号、UP 主名与评论区昵称。
> 这些都是 B站上任何人打开就能看到的内容，**未做匿名化**——保留原样是为了让样例可追溯、
> 能点进去核对。若你要把它当模板复用，请自行替换成自己的议题与数据。
>
> 报告里的评级（如 `B2`）是**分析者针对该议题给出的判断**，不是平台评分，也不是对本人的评价。

| 文件 | 说明 |
|---|---|
| `20261021-主流二游社区·B站信息深入报告（第二轮）.html` | 真实产物：56 KB 报告 → 94 KB 单文件 HTML |

这份样例的来源与状态：

- **内容**来自 2026-10-21 的一次真实运行（议题「主流二游社区」，9 条深挖视频，
  727 条评论取样，84 次上游调用）。
- **编排**在 2026-10-22 按新版六节重排（结论 → 发现 → 冲突 → 缺口与建议 →
  检索范围与偏差声明 → 信源地图），**结论与数字均未改动**；原文的
  `§3.x` / `§4-x` 引用已机械映射为 `§2.x` / `§3-x`。
- **PDF 不入库**（3.5 MB，随时可重新渲染）：`python scripts/render_briefing.py --md … --pdf`。

打开它能看到的版式要素（都在 `assets/template/briefing.css` 里定义）：

| 要素 | 位置 |
|---|---|
| 报头（kicker / 标题 / 元信息） | 顶部，kicker 随模式切换（深入报告 vs 简报） |
| **读图口径**（A–F、1–4、证据强度、缺口三类） | 报头下方，**脚本自动生成**，不进 md |
| 证据概览（评级分布 / 证据强度分布） | 口径块下方，脚本统计；**评级按信源地图去重后的 BV 计数**，标题里注明条数 |
| 评级徽章（`B2` 等，悬停有解释）、证据徽章、缺口徽章 | 各表内 |
| 冲突节的双栏对照（A 方 / B 方 / 我的处理） | §三 |
| 8–9 列宽表（信源地图，`table.wide` 缩到 13.6px + 窄屏横向滚动） | §六 |
| 打印版（A4、表头重复、行不跨页断开） | PDF |

> ⚠️ **不要直接把本目录的 HTML 当模板改**。它是生成的产物；
> 改版式改 `assets/template/briefing.css`，改结构改 `scripts/render_briefing.py`。
